# Auditoría de seguridad y funcionalidad

Este proyecto integra un backend en Node.js con Express y un frontend en React para gestionar incidentes de ciberseguridad. Sus funcionalidades principales permiten listar, buscar, crear, actualizar y eliminar registros, así como filtrar incidentes por prioridad y consultar detalles por identificador. La interfaz facilita el registro de datos como tipo de amenaza, sistema afectado, estado, descripción, evidencia y fecha de creación, lo cual ayuda a mantener un control operativo claro de cada evento.

Dentro de las mejoras recomendadas, se sugiere usar autenticación y autorización para evitar acceso no autorizado, implementar persistencia con base de datos en lugar de almacenar datos en memoria, y reforzar la validación de entradas para impedir valores nulos, inválidos o maliciosos. También es importante añadir variables de entorno, paginación, auditoría de cambios, manejo de sesiones y registros de seguridad para mejorar trazabilidad y mantenimiento. Una capa de control de CORS más estricta y pruebas automáticas fortalecerían la calidad del proyecto.

Las vulnerabilidades más relevantes incluyen la ausencia de protección por identidad, la exposición de endpoints sin restricciones, la falta de sanitización de campos, la ausencia de limitación de peticiones y la confidencialidad débil de la información. Además, el uso de CORS abierto y la falta de validación de URLs o textos pueden facilitar ataques de manipulación, abuso de API y riesgos de inyección. El proyecto presenta una base funcional sólida, pero antes de desplegarse en producción requiere reforzar seguridad, control de acceso y buenas prácticas de desarrollo. También se recomienda cifrar información sensible, revisar registros y actualizar dependencias con frecuencia. Un entorno con pruebas, monitoreo y respaldos mejoraría la resiliencia ante incidentes y reduciría la superficie de ataque. Además, la documentación técnica y la segmentación de servicios facilitarían la evolución segura del sistema sin comprometer la continuidad operativa en el futuro productivo.
